# VisibleHand Compliance and Workplace Policies

VisibleHand policies are [publicly published](http://github.com/visiblehandinc/policies)

This repository holds two sets of policies: the information security and privacy policies built on the HIPAA Security Rule and the HITRUST Common Security Framework, and the workplace policies that govern how VisibleHand treats and protects its own workforce.

All policies are licensed under [CC BY-SA 4.0](http://creativecommons.org/licenses/by-sa/4.0/).

Policies were last updated September 24th, 2026.
